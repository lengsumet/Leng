# Bun Elysia Project

This project is a backend server built with Bun and Elysia.js.

## Prerequisites

- [Bun](https://bun.sh/)

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd <project-directory>
   ```
3. Install dependencies:
   ```bash
   bun install
   ```

## Running the Server

To start the server, run the following command:

```bash
bun run src/index.ts
```

The server will start on port 3000. You can access the "Hello World" endpoint at `http://localhost:3000/`.
