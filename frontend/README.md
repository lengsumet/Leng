# Frontend Store Application

This project was bootstrapped with Vite and uses React with Material-UI.

## Available Scripts

In the project directory, you can run:

### `npm install` or `bun install`

Installs all the necessary dependencies for the project. (Note: The project was initialized with `npm` due to worker environment specifics, so `npm install` might be more straightforward initially).

### `npm run dev` or `bun run dev`

Runs the app in the development mode.
Open [http://localhost:5173](http://localhost:5173) (or the port shown in your terminal) to view it in the browser.

The page will reload if you make edits.
You will also see any lint errors in the console.
